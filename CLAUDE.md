# CLAUDE.md

Этот файл содержит инструкции для Claude Code (claude.ai/code) при работе с кодом в этом репозитории.

## Что это за репозиторий

Единственная статичная русскоязычная персональная страница-профиль (лендинг) для Татьяны Слободич (психолог, предприниматель, мама). Здесь нет системы сборки, менеджера пакетов, линтера или тестов — весь сайт представляет собой один самодостаточный файл `index.html` со встроенным CSS, без JavaScript и внешних зависимостей.

## Работа с сайтом

- Открывайте `index.html` напрямую в браузере для предпросмотра — сервер или сборка не требуются.
- Все стили находятся в блоке `<style>` в начале `index.html`, используются CSS-переменные (`--accent`, `--paper`, `--ink` и т.д.), заданные в `:root`, для цветовой палитры.
- Вёрстка — обычные CSS Grid/Flexbox (`.about-grid`, `.facts-grid`, `.directions`/`.direction`) с адаптивными брейкпоинтами через `@media (max-width: ...)` — без фреймворков.

## Структура контента

- `index.html` — итоговая отображаемая страница; `1profile.md`, `про-меня.md`, `факты.md` и `проекты.md` — исходные материалы (полный профиль, краткое «обо мне», список фактов, проекты/достижения), на основе которых построены разделы HTML. Эти файлы дублируют одни и те же биографические факты в разных формулировках — при обновлении одного файла проверяйте остальные на расхождения.
- `images/` содержит исходные фотографии, на которые ссылается `index.html`, названные по временной метке съёмки (`YYYY_MM_DD_HH_MM_SS_IMGxxxx.ext`). `index.html` жёстко прописывает эти пути, поэтому не переименовывайте файлы изображений без обновления соответствующих ссылок `<img src>`.
